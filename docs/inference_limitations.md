# Inference and implementation limits

CCC tests coefficient restrictions under linear conditional means and the chapter's sampling assumptions. It does not test unconditional, conditional or integrated parallel trends. Covariates must be unaffected by treatment, with no anticipation. Selection cannot repair bad controls, misspecification, missing overlap or dependence.

HC1 handles the specified heteroskedastic sandwich calculation, not arbitrary serial or within-region dependence. Repeated individual IDs do not turn this into panel/cluster inference. Cluster, survey, observation weights and treatment reversals are unsupported. No ATT estimator, jackknife inference, selected-model confidence guarantee or confidence bands is included. The additive second stage does not exhaustively represent nonadditive heterogeneity.

Every required auxiliary design and restriction covariance must be full rank. Current engines reject cross-product condition above 1e12 and cap slope parameters at 2000. These are conservative software safeguards, not statistical thresholds. Large numbers of restrictions and weak within-cell information remain substantive concerns even when computations pass. Covariance matrices remain dense in the number of slopes; the observation-by-full-design matrix is not materialized. The million-row benchmark had K=1 and U=24; it does not establish ACS-scale high-dimensional performance.

Dates use ordered numeric encodings. With cohort input, time zero is rejected because cohort zero means never treated. Calendar-date parsing and automatic anticipation windows are not offered; apply an explicit defensible sample restriction. Unknown cohorts are not never treated. Different-language sample-exclusion counts can be partitioned in different order, but analysis masks and fitting samples must agree.

Stata plot controls are fixed never-treated regions. R/Python additionally allow fixed not-yet-treated controls eligible throughout the entire window. Stata selects focal/window subsets through if/in and matched controls through a documented matrix of region codes; R/Python also offer named focal/window options. The Stata plotting engine currently estimates the whole diagnostic family even for an individual panel, so a raw-only request can fail if a covariate-adjusted model is unidentified. This is an explicit first-version limitation; no silent subset is delivered.

Zero, pooled, and explicit basis references are software conventions. Heterogeneous adjusted trend shapes can depend on reference values; extrapolation flags use marginal ranges only. No empirical matching or exact reproduction of the chapter's ACS figures is claimed. Adjacent observed changes record baseline dates and are not labeled annual when spacing is unknown.
