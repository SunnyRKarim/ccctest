# Changelog

## 0.1.0 public source release

Publication and maintainer metadata updated for Sunny Karim's public repository. Source algorithms and validation fixtures are unchanged from the private development snapshot. The original validation record is retained, and a fresh public CI run is expected after publication.

### Original implementation

Native Stata/Mata, R and Python CCC tests; pooled HC1/OLS, additive second-stage Holm, gated selection, explicit failure states; standalone six-panel trend diagnostics with integrated prediction audit tables; offline synthetic demonstrations; shared reference fixtures and cross-language checks. No ATT estimator, cluster/survey inference, observation weights, confidence bands or open-source redistribution permission.

### Publication licensing clarification

The copyright notice explicitly permits use of unmodified copies for research, teaching, and evaluation, but reserves modification and redistribution rights. No statistical implementation files were changed in this release preparation.
