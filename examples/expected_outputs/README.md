# Verified demonstration outputs

These files were generated by the offline Stata conference demonstration on StataNow 18.5 SE. `ccc_trends` uses the shared six-period source fixture; `ipt_trends` and `cpt_trends` use the separately documented eight-period algebraic fixture. CSV files are numeric graph data; GPH files are editable native Stata graphs. The DTA is the original demonstration's numeric series.

`python_plots.png` and `r_plots.png` show the same IPT fixture through the native Python and R interfaces. Numerical arrays, rather than image pixels, are compared across languages. See `docs/validation_report.md` for the independent plot checks and limitations.

Regenerate from the repository root using the commands in README.md. No empirical ACS data or original empirical chapter figure is included.
